# Licensing Decision

이 package는 GitHub 공개 준비 상태이지만 **repository 자체의 라이선스는 자동으로 선택하지 않았습니다.** 라이선스 선택은 저작권/배포 정책 결정이므로 저장소 소유자가 확정해야 합니다.

일반적으로 코드/config glue repository에는 Apache-2.0 또는 MIT를 검토할 수 있지만, 실제 선택 전 조직 정책과 포함 파일의 저작권을 확인하십시오.

이 저장소는 Open5GS, Osmocom/OsmoSTP, srsRAN 4G, srsRAN Project, ss7simulator의 upstream source를 통째로 포함하지 않습니다. 각 upstream component는 각자의 라이선스를 따릅니다.
